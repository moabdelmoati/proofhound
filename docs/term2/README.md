# Term 2 — Multi-Agent Architecture

Specialized agents (Analyzer, Harness, Fuzzer, Triage, Scheduler, Patcher) coordinate in one
pipeline. Term 2 compares three configurations on JavaScript, TypeScript and Python:
single-agent with the local model, single-agent with the Claude API, and the multi-agent pipeline.

Code: `src/proofhound/multi_agent/`, built on the shared `src/proofhound/core/`.
Term 2 documents (architecture, results, report) go in this folder.
